התוסף של Clearly – התקנה אחת, ואחר כך הוא מתעדכן לבד
==========================================================

מה יש בתיקייה הזו
- extension          התוסף עצמו (את התיקייה הזו טוענים בכרום)
- Clearly-auto-update-ON.bat    מפעיל עדכון אוטומטי (לוחצים פעמיים, פעם אחת בלבד)
- Clearly-update.bat            עדכון ידני, אם רוצים לבדוק עכשיו
- Clearly-auto-update-OFF.bat   מכבה את העדכון האוטומטי

התקנה (פעם אחת, כ-3 דקות)
1. מחלצים את הקובץ שהורדתם לכונן C (קליק ימני ← "חלץ הכול" ← בשדה כותבים C:\ ).
   תיווצר תיקייה C:\Clearly
2. בכרום, בשורת הכתובת, כותבים: chrome://extensions
   אם כבר מותקן "המחבר של Clearly" ישן, לוחצים עליו "הסרה".
3. למעלה מדליקים "מצב מפתח", ואז "טעינת פריט לא ארוז", ובוחרים את התיקייה C:\Clearly\extension
   (בתוכה רואים את הקובץ manifest.json).
4. לוחצים פעמיים על Clearly-auto-update-ON.bat.
   אם חלון כחול של Windows מזהיר: "מידע נוסף" ← "הפעל בכל זאת". הקובץ רק מוריד את התוסף מהאתר של Clearly.
5. מתחברים לתוסף (סמל הפאזל ← המחבר של Clearly) עם אותו מייל וסיסמה כמו באפליקציה.

איך מתעדכנים אחר כך
- הקובץ בודק גרסה חדשה כל יום ב-12:00 ובכל כניסה למחשב, ומחליף את הקבצים לבד.
- כדי שהגרסה החדשה תתחיל לעבוד: פותחים את כרום מחדש, או נכנסים ל-chrome://extensions ולוחצים
  על סמל הרענון (חץ מעגלי) בכרטיס של התוסף. זהו, בלי הורדה ובלי התקנה מחדש.
- אפשר גם ללחוץ פעמיים על Clearly-update.bat כדי לבדוק עכשיו.
